# 💌 ComplimentBot

Telegram-бот: через Gemini каждый день присылает ей комплименты — утром и вечером.

## Запуск
1. Создай бота у @BotFather и возьми токен.
2. Возьми ключ Gemini: https://aistudio.google.com/apikey
3. `cp .env.example .env` и заполни.
4. `.venv/bin/pip install -r requirements.txt`
5. `.venv/bin/python main.py`
6. Отправь ей ссылку на бота. Хозяйкой станет тот, кто первым нажмёт /start, — поэтому сам не жми.
   Чтобы сменить хозяйку, останови бота и удали `data/state.json`.

Бот должен работать постоянно (VPS, Raspberry Pi или всегда включённый компьютер).

## Что умеет
- 🗓 Расписание она настраивает сама: /schedule (кнопками — добавить/удалить время, «только по запросу»).
  По умолчанию 10:00 и 23:00. /now — сообщение прямо сейчас, /pause и /resume.
- 🤖 Перебирает бесплатные модели Gemini: кончился лимит у одной — берёт следующую (/models — статус).
- ☀️ Утро: приветствие с учётом дня недели, комплимент, «суперсила дня», предсказание под спойлером.
- 🌙 Вечер: комплимент, секретное послание под спойлером, пожелание спокойной ночи.
- 🎂 В день рождения (`GIRL_BIRTHDAY`) — особое поздравление.
- Кнопки: ещё комплимент, предсказание, печенька, загадка с ответом под спойлером,
  «причина №N, почему ты классная», настроение (поддержка).
- Можно просто писать боту — он ответит.
- Темы и формы комплиментов каждый раз выбираются случайно (прогноз погоды, баг-репорт, хокку…),
  последние 40 комплиментов запоминаются, чтобы не было повторов.
- Если Gemini недоступен, отправляется запасной текст из `fallback.py`.

## Ещё команды
`/stats` — статистика, `/models` — какие модели Gemini сейчас работают.

Её описание и список тем — в `girl_profile.py`. Допиши туда детали: чем больше подробностей, тем точнее комплименты.

## Деплой на сервер через Portainer (Git)
1. Залей проект в git-репозиторий (`.env` и `data/` в `.gitignore` — секреты не попадут).
2. Portainer → **Stacks → Add stack → Repository**:
   - Repository URL — ссылка на репозиторий (для приватного включи Authentication и укажи токен);
   - Compose path — `docker-compose.yml`.
3. В **Environment variables** добавь минимум `BOT_TOKEN` и `GEMINI_API_KEY`
   (остальные — по желанию, см. `.env.example`).
4. **Deploy the stack**. Обновление после `git push` — кнопка **Pull and redeploy** в стеке
   (или включи GitOps updates, чтобы Portainer подтягивал изменения сам).

Данные бота (хозяйка, расписание, история без повторов) лежат в volume `compliment-data`
и переживают пересборку. Не запускай одновременно локальную копию с тем же токеном — Telegram
отдаёт сообщения только одному экземпляру.

Версии всех библиотек залочены в `requirements.lock`, базовый образ — `python:3.13.16-slim`.
