# 💌 ComplimentBot

Telegram-бот: через Gemini каждый день присылает ей комплименты — утром и вечером.

## Запуск
1. Создай бота у @BotFather и возьми токен.
2. Возьми ключ Gemini: https://aistudio.google.com/apikey
3. `cp .env.example .env` и заполни.
4. `.venv/bin/pip install -r requirements.txt`
5. `.venv/bin/python main.py`
6. Впиши её Telegram ID в `ALLOWED_USERS` (несколько — через запятую) и отправь ей ссылку на бота.
   Ей нужно один раз открыть бота и нажать /start — Telegram не даёт ботам писать первыми.
   Всем, кого нет в списке, бот не отвечает.

Бот должен работать постоянно (VPS, Raspberry Pi или всегда включённый компьютер).

## Что умеет
- 🗓 Расписание она настраивает сама: /schedule (кнопками — добавить/удалить время, «только по запросу»).
  По умолчанию 10:00 и 23:00. /now — сообщение прямо сейчас, /pause и /resume.
- 🤖 Перебирает бесплатные модели Gemini: кончился лимит у одной — берёт следующую (/models — статус).
- ☀️ Утро: приветствие с учётом дня недели, комплимент, «суперсила дня», предсказание под спойлером.
- 🌙 Вечер: комплимент, секретное послание под спойлером, пожелание спокойной ночи.
- 🎂 В день рождения (`GIRL_BIRTHDAY`) — особое поздравление.
- Кнопки: ещё комплимент, предсказание, печенька, загадка с ответом под спойлером,
  «причина №N, почему ты классная», настроение (поддержка).
- Можно просто писать боту — он ответит.
- Темы и формы комплиментов каждый раз выбираются случайно (прогноз погоды, баг-репорт, хокку…),
  последние 40 комплиментов запоминаются, чтобы не было повторов.
- Если Gemini недоступен, отправляется запасной текст из `fallback.py`.

## Ещё команды
`/stats` — статистика, `/models` — какие модели Gemini сейчас работают.

## Админ (`ADMIN_ID`)
Рассылку админ не получает, но бот шлёт ему журнал, всё **без звука**:
отправки (✅ какой моделью или запасной текст), её нажатия и сообщения (👆), чужие попытки зайти (🚫),
сбои Gemini (⚠️), ошибки с короткой выжимкой (❌), пропажа и возврат сети (🌐) и сводку за день в `ADMIN_SUMMARY_TIME`.
Пока Telegram недоступен, журнал копится и приходит одной пачкой.

Управление из админ-бота: в боте нет команды `/admin`, ручные действия идут через HTTP control API (`control.py`, порт 8081, заголовок `X-Control-Token`, токен берётся из `CONTROL_TOKEN`; без токена API выключен). Эндпоинты: `GET /status`, `POST /send`, `/plan`, `/unplan`, `/pause`, `/schedule/add`, `/schedule/remove` — отправить сообщение сейчас, запланировать разовую отправку, поставить на паузу, изменить расписание, получить статус.
запланировать разовую отправку на время, пауза расписания, статистика и статус.

Надёжность: слот считается отправленным только после успешной отправки, при ошибке повтор через 2–5 мин в
пределах 2 часов. Если пропал интернет, бот раз в полчаса проверяет связь (переживает перезапуск), а когда
она появится, шлёт «🐗 Кабанский сервер барахлит…» и следом сам комплимент.

Личный профиль (описание, темы, прозвища) хранится в `girl_profile.py`, который не попадает в git (он в `.gitignore`). Скопируй шаблон `girl_profile_example.py` в `girl_profile.py` и заполни своими деталями: чем больше подробностей, тем точнее комплименты. Если файла нет, бот берёт шаблон. В Docker-образ файл попадает только при локальной сборке; при деплое из git будет использован шаблон.

## Деплой на сервер через Portainer (Git)
1. Залей проект в git-репозиторий (`.env` и `data/` в `.gitignore` — секреты не попадут).
2. Portainer → **Stacks → Add stack → Repository**:
   - Repository URL — ссылка на репозиторий (для приватного включи Authentication и укажи токен);
   - Compose path — `docker-compose.yml`.
3. В **Environment variables** добавь минимум `BOT_TOKEN`, `GEMINI_API_KEY`, `ALLOWED_USERS` и `ADMIN_ID`
   (остальные — по желанию, см. `.env.example`). В `docker-compose.yml` значений нет — всё только из env.
4. **Deploy the stack**. Обновление после `git push` — кнопка **Pull and redeploy** в стеке
   (или включи GitOps updates, чтобы Portainer подтягивал изменения сам).

Данные бота (расписание, история без повторов) лежат в volume `compliment-data`
и переживают пересборку. Не запускай одновременно локальную копию с тем же токеном — Telegram
отдаёт сообщения только одному экземпляру.

Версии всех библиотек залочены в `requirements.lock`, базовый образ — `python:3.13.16-slim`.
